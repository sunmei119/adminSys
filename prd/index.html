桂教通运营管理后台 - 菜单管理产品需求文档

一、概述

1. 产品目标

为平台运营人员提供统一的菜单配置能力：按菜单位置维护菜单的打开方式、层级顺序与机构部门范围，配置发布后同步到各端，保证不同机构、不同部门看到的菜单与自身职责一致。

2. 本期范围

包含菜单列表、新增菜单、编辑菜单，以及选择机构、选择部门两个辅助弹窗；包含附件配置管理（列表、新增、编辑、启用、停用）；不含菜单分组、菜单回收站、权限模板、附件清理策略。

二、角色与权限

角色权限
平台管理员查看全部菜单，新增、编辑、删除菜单，发布菜单配置；查看全部附件配置，新增、编辑、启用、停用
运营人员可在菜单的「角色配置」中被选择；本期不开放菜单管理入口

三、页面说明

page-1 菜单管理

以列表方式展示全部菜单，支持按菜单名称、更新时间、菜单位置、所属机构、菜单链接、菜单层级筛选；列表展示父级菜单、打开方式、跳转应用、所属机构、可见部门、菜单链接、菜单图片、菜单层级、菜单顺序与更新时间；行内可编辑、删除，页头可新增、发布菜单配置。

page-2 新增菜单

分「基础信息」「归属与范围」「展示与权限」三个可收起分区录入，底部固定保存/取消。

page-3 编辑菜单

与新增同一页面，进入时回显已有配置；修改菜单位置会清空已选父级菜单。

page-4 附件配置管理

列表展示各业务系统在具体机构下的附件配置，支持按业务系统名称、机构名称、存储方式、状态筛选；可新增、编辑配置，并按需启用或停用。

四、详细需求说明

4.1 菜单列表

  1. 默认按更新时间倒序展示，字段见数据字典。
  2. 所属机构列：无机构授权显示「全平台」；单机构显示机构名称；多机构显示「首个机构 等 N 个」，悬停可查看全部机构。
  3. 可见部门列：全部部门显示「全部部门」；部分部门显示「N 个部门」；同一菜单既有全部门机构又有指定部门机构时显示「全部 + N 个」，悬停按机构展示部门明细。
  4. 删除需二次确认，确认后菜单从列表移除。
  5. 「发布菜单配置」需二次确认，确认后配置生效并刷新发布时间。

4.2 基础信息

  1. 菜单位置为必填，选项为 pc企业-宪法赛事评审、pc企业-评审活动管理、pc管理端-平台功能设置。
  2. 菜单名称为必填，最多 30 字。
  3. 打开方式必填，三选一，字段联动：
    • URL链接：菜单链接必填；是否外部链接可选内部跳转/外部跳转/内嵌，默认内部跳转。
    • 应用链接：跳转应用ID必填，跳转应用名称选填。
    • 单点跳转链接：菜单链接必填，按单点登录链路处理。
  4. 菜单链接以 http:// 或 https:// 开头按外链处理，不带协议按大平台内链处理。

4.3 归属与范围

  1. 可添加多个机构授权，每条授权 = 一个机构 + 该机构下的可见部门。
  2. 所属机构非必填，选择入口为弹窗：支持按机构名称/机构ID搜索，列表展示机构名称、机构ID、类型、管理员，单选后回填并关闭。
  3. 可见部门通过「选择部门」弹窗配置：左侧为所选机构的部门树（可勾选、默认展开），右侧展示「已选部门（N）」清单，未选时显示「暂无选中」，底部取消/确定。
  4. 未选择机构时「选择部门」按钮禁用，提示先选择所属机构。
  5. 更换机构时清空该行已选部门。
  6. 存在未选机构的空行时，点击「添加机构」提示「请先选择所属机构」并不新增；保存时自动丢弃未选机构的空行。
  7. 未配置任何机构授权时，菜单全平台可见。

4.4 展示与权限

  1. 父级菜单为选填，候选取值范围见 4.4.1。
  2. 菜单层级必填，选项一级菜单/二级菜单/三级菜单，默认一级菜单。
  3. 菜单顺序必填，为非负整数，默认 1，用于同位置同层级排序。
  4. 角色配置为多选，选项平台管理员/运营人员。
  5. 是否隐藏必填，默认显示。
  6. 菜单图片选填，支持 jpg、png、svg，单文件不超过 1M，格式或大小不符时提示且不接受上传。

4.4.1 父级菜单与菜单位置的联动（强约束）

  1. 父级菜单只能展示当前菜单位置下的菜单：候选列表 = 菜单位置与当前表单所选位置一致的菜单。
  2. 候选排除当前编辑菜单自身；新增时无可排除对象。
  3. 菜单位置未确定时没有候选，下拉为空；菜单位置为必填，不选位置无法保存。
  4. 修改菜单位置后，已选父级菜单立即清空，需在新位置的候选中重新选择，避免出现「父级菜单与子菜单不属于同一位置」的脏配置。
  5. 父级菜单下拉旁常驻提示「仅展示当前菜单位置下的菜单」，让配置者明确范围。

4.5 保存与生效

  1. 必填校验不通过时不允许保存，定位到对应分区与字段。
  2. 保存成功回到列表并刷新该菜单的更新时间。
  3. 保存后为配置态，需发布菜单配置才对端上生效。

4.6 附件配置管理

  1. 列表字段：业务系统名称、机构名称、存储方式、状态、备注说明、更新时间、操作。
  2. 筛选：业务系统名称（模糊匹配）、机构名称（下拉）、存储方式（下拉）、状态（启用/停用）；支持搜索与重置。
  3. 新增与编辑共用弹窗，字段如下：
    • 业务系统名称：必填，最多 50 字。
    • 机构名称：必填，从统一机构库下拉选择，支持按名称搜索。
    • 存储方式：必填，下拉选项为一体机、信创云、天翼云、东信云，新增时默认一体机。
    • 备注说明：选填，最多 200 字，输入区显示字数计数。
  4. 新增配置默认状态为启用；保存后刷新该条配置的更新时间。
  5. 启用/停用：
    • 状态为启用时，行内操作显示「停用」；点击后二次确认，确认后状态变为停用。
    • 状态为停用时，行内操作显示「启用」；点击后直接启用并提示。
    • 停用后该业务系统的附件上传与下载不可用，配置保留，可随时重新启用。
  6. 本期不提供删除入口，不再使用的配置通过停用下线。

五、数据字典

字段类型必填说明
menu.idstring是菜单唯一编号，系统生成
menu.positionenum是菜单位置：pc企业-宪法赛事评审 / pc企业-评审活动管理 / pc管理端-平台功能设置
menu.namestring是菜单名称，最多 30 字
menu.open_typeenum是打开方式：URL链接 / 应用链接 / 单点跳转链接
menu.linkstring条件必填菜单链接；URL链接、单点跳转链接时必填
menu.link_typeenum否内部跳转 / 外部跳转 / 内嵌，仅 URL链接 生效，默认内部跳转
menu.app_idstring条件必填跳转应用ID，应用链接时必填
menu.app_namestring否跳转应用名称
menu.parent_namestring否父级菜单；候选仅限当前菜单位置下的菜单，排除自身
menu.levelenum是菜单层级：一级菜单 / 二级菜单 / 三级菜单
menu.orderint是菜单顺序，同位置同层级排序，默认 1
menu.rolesstring否角色配置，多选：平台管理员 / 运营人员
menu.hiddenbool是是否隐藏菜单，默认显示
menu.imagestring否菜单图片文件名，jpg/png/svg，≤1M
menu.grant.orgstring否机构授权；为空表示全平台可见
menu.grant.deptsstring否该机构的可见部门；为空表示该机构全部部门
menu.updated_atdatetime是最近更新时间，系统生成
attachment.idstring是附件配置唯一编号，系统生成
attachment.system_namestring是业务系统名称，最多 50 字
attachment.org_idstring是机构ID，取自统一机构库
attachment.storageenum是存储方式：一体机 / 信创云 / 天翼云 / 东信云，默认一体机
attachment.remarkstring否备注说明，最多 200 字
attachment.statusenum是启用（enabled）/ 停用（disabled），新增默认启用
attachment.updated_atdatetime是最近更新时间，系统生成

六、权限汇总

页面/对象平台管理员运营人员
菜单管理查看全部、筛选、新增、编辑、删除、发布无入口
新增菜单录入并保存无入口
编辑菜单回显并保存无入口
附件配置管理查看全部、筛选、新增、编辑、启用、停用无入口

按钮级口径：

  • 平台管理员：可使用「新增菜单」「发布菜单配置」「编辑」「删除」「添加机构」「选择机构」「选择部门」「保存」「取消」。
  • 平台管理员：在附件配置管理中可使用「搜索」「重置」「新增附件配置」「编辑」「启用」「停用」。
  • 菜单数据的可见范围由 menu.grant（机构 + 部门）与 menu.roles 共同决定，对端上用户生效，不改变后台配置权限。

七、状态机

配置态（新增/编辑/删除已保存）→ 发布确认 → 生效态。

  • 配置态：仅后台列表可见，端上仍为上一次发布结果。
  • 生效态：端上按最新位置、层级、可见范围展示。
